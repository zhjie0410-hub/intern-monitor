## 一、引擎做法

```
抓包 → 页面自己发的列表请求 → 解析响应 JSON → 按 spec 映射字段
```
分两种翻页策略：
- `click`：点页面上的「下一页」，让页面自己发请求（适用带签名的 SaaS，如得物）
- `replay`：抓到请求后替换页码重放（适用无签名接口）
