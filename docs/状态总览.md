## 四、口径差异清单（写代码时必须注意）

| 差异点 | 各家情况 |
|---|---|
| **分页参数名** | 字节 `offset`、腾讯 `pageIndex`、京东 `pageIndex`（0 起）、美团 `page.pageNo`（1 起）、小红书 `pageNum`、阿里 `pageIndex`、蚂蚁 `pageIndex`、拼多多 `page`、网易 `currentPage` |
| **时间字段名** | 字节 `publish_time`、京东 `publishTime`、美团 `refreshTime`、小红书 `publishTime`、阿里 `publishTime`、蚂蚁 `publishTime`(ISO)、拼多多 `publishDate`、网易 待确认、腾讯 无 |
| **时间格式** | 毫秒时间戳（字节/京东/美团/拼多多）、ISO 8601（蚂蚁）、YYYY-MM-DD（小红书/阿里/百度） |
| **实习过滤依据** | 字节 `recruit_type=实习`、腾讯 `projectMappingIdList=[104]`、京东 `planIdList=[45]`、美团 `hiringType=4_6`、阿里 `batchId=100000560002`、蚂蚁 `batchIds=[25051200066269]`、小红书 `jobProjects=[madang_trainee]`、网易 `workType=1`、小米 `project=实习` |
| **城市字段** | 数组（字节/蚂蚁）、空格串（腾讯，含"深圳总部"）、`cityList`（美团） |
| **需要 token** | 阿里 `_csrf`、蚂蚁 `ctoken`、美团 `u_query_id` |
